# App Store screenshots

Place PNG screenshots here for the Nextcloud App Store listing. `appinfo/info.xml`
already points at these raw GitHub URLs:

| File | Suggested content |
|------|-------------------|
| `dashboard.png` | Live mission / status dashboard |
| `history.png` | Mission history with footprint replay |
| `settings.png` | Schedule / preferences / admin onboarding |

Capture at ~1280×720 or wider from a real session. Until the PNGs land, App
Store review may warn on missing screenshot assets — regenerate after UI polish
and commit the binaries (or update the URLs).
